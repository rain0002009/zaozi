# 铸武台武器与装备特性配置台 (Weapon & Equipment Configurator)

## 目标
构建一个独立路由的武器与装备配置管理页面（`/?view=weapon-editor`），支持：
1. 装备类型解构：拆分为武器（Weapon）、防具（Armor）、宝具（Talisman）等基础类别；
2. 基础属性调节：根据不同装备类别配置伤害、攻速、射程、击退、弹速、减伤率、额外生命等；
3. 特性系统（Traits）：支持 10 种特色战斗/防御特性（击退、烈焰灼烧、一击必杀、奔雷连环、极寒迟滞、墨血汲取、狂风穿透、荆棘反噬、震地眩晕、墨影余波），支持拖拽/点击装配并调节每个特性的数值强度；
4. 自由字组合配方：支持手动输入任意数量汉字作为铸造配方；
5. 视觉与动作模组配置：表单显式选择近战/远程、兵刃形态（刀/枪/斧/弓/盾）与五行属性；
6. 纯 JSON 代码生成器：提供可视化配置、实时 JSON 生成预览、一键复制、下载与导入功能。

## 验收标准
- [x] 访问 `/?view=weapon-editor` 可直接进入全屏响应式 Web 管理页面，并在游戏中（铸武台或控制台）提供快捷入口跳转。
- [x] 左侧展示装备列表，支持分类筛选（全部/武器/防具/宝具），支持新建、克隆与删除装备。
- [x] 中间区域支持表单编辑基础信息、手动输入汉字配方、配置基础属性与动作/视觉形态。
- [x] 提供特性库卡片，支持将特性拖入或点击装配至装备，并能展开编辑特性的专属参数（如触发概率、灼烧伤害、反伤比例等）。
- [x] 右侧实时展示当前及全量 JSON 代码，提供复制到剪贴板、下载 `weapons-config.json` 与导入已有 JSON 功能。
- [x] 预设完整收录现有游戏已有的 14 种词组武器，并为部分武器预装配对应特性作为示范。
