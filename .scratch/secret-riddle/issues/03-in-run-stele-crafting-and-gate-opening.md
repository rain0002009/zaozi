# 03 — 局内宣纸造字、谜底校验与开门消耗 (In-Run Stele Crafting & Gate Opening)

**What to build:** 玩家点击解谜古碑可呼出米字格宣纸手写画板，读取出征的【携带笔画】现场手写造字。书写后提交验证：若汉字不匹配给出温和反馈且不扣除任何资源；若汉字与谜底一致且笔画充足，则扣除对应笔画、凝出字并瞬间作为钥匙消耗开门，过渡进入秘境殿堂。
