# 01 — 路线节点生成与秘境行路卡片 (Route Generation & Secret Node)

**What to build:** 在出征行路图（RouteScene）中，按概率（15%~25%）在可选路线节点中生成特殊的金色【字谜秘境】节点。玩家能够查看秘境节点的专属标识、危险提示和高奖励说明，点击即可选择该节点并踏入字谜秘境。

**Blocked by:** None — can start immediately

**Status:** closed

- [x] 出征状态模型扩展支持 `secret_riddle` 路线类型，包含专属标题、副标题、危险度与金色主题色彩配置
- [x] 路线生成逻辑按设定概率（15%~25%）在非首领区域的候选路线中生成字谜秘境节点
- [x] 行路图界面展示金色秘境卡片，带有独特的视觉印章与“高奖励/字谜”说明文案
- [x] 点击秘境卡片可正常选中该路线并过渡切换至对应区域场景
- [x] 编写并执行单元测试，验证路线生成概率分布、节点数据完整性与路线选择契约
