# 001-handwriting-recognition-workshop

## 目标
将「造字台」从原先的 3×3 米字格点选摆放笔画，全面升级为**毛笔宣纸手写画板**，并接入开源离线手写汉字识别库（HanziLookupJS + MMAH 汉字笔画数据集），实现真实书写汉字、实时识别候选字、笔画资源校验与【凝字成符】入库的完整闭环。

## 验收标准
1. **离线高精度识别**：集成 HanziLookupJS 与 `mmah.json`（支持 9,507 个汉字，离线运行，耗时 <20ms，无外部网络依赖）。
2. **毛笔书法宣纸画板**：在基地造字台提供宣纸米字格手写板，支持鼠标/触摸自由运笔、水墨拖尾笔触、撤销单笔与清空重写。
3. **实时候选字与词条联动**：运笔抬笔后实时给出候选字（Top 6），支持点击切换候选；对收录于兵道词库的汉字（刀、弓、盾、木、火、金、石、水、十、人、大、风、雷、枪、斧）高亮标注兵刃/属性词缀。
4. **笔画消耗与凝字入库**：比对玩家仓中笔画库存与目标汉字配方，充足时点亮【凝字成符】，扣减对应笔画并收入字库，可直接用于铸武台组词锻造。
5. **无编译与构建错误**：`npx tsc --noEmit` 与 `npx vite build` 均 0 错误通过。
