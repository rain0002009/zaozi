# 三域出征纵向切片

## 目标
用最小但完整的一次出征验证“基地准备 → 路线选择 → 区域战斗 → 笔画带回 → 造字 → 再次出征”的核心循环。

## 范围说明
三域结构只用于当前纵向切片；完整设计仍以每次出征 5–8 个区域为目标。

## 验收标准
- [x] 主菜单进入基地，基地展示库存、装备字和造字配方。
- [x] 可用库存笔画组成“火”和“盾”。
- [x] 出征包含两次路线决策和第三域首领。
- [x] 普通追击、远程攻击、蓄力冲锋三类敌人有不同战斗行为。
- [x] “刀”控制扇形近战，“火”提供主动火球，“盾”提供被动减伤。
- [x] 区域结束可继续深入或携物撤退。
- [x] 胜利、撤退和战败均回到基地结算；战败只保留四分之一携带笔画。
- [x] 基地库存和已组成的字保存在浏览器本地。
- [x] 桌面画面完成菜单、基地、路线和战斗截图检查。
- [x] `pnpm build` 通过。
