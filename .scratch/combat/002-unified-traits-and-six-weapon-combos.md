# 统一特性体系、六大兵刃连击序列与兵刃拓片双锚点系统

## 目标

1. 统一特性架构（一切皆特性）：重构 `TraitMeta` 与 `CompoundEquipment`，合并基础数值属性、元素属性与法则特性，采用极简通俗中文命名（如“吸血”、“灼烧”、“斩杀”）。
2. 实现六大兵刃形态（刀、枪、剑、戟、斧、弓）连击定义与打击节奏（2 到 5 连击）。
3. 建立兵刃拓片外形上传与双锚点（握持点、刃尖点）及朝向校准系统，支持贴图优先与程序化水墨回退双模渲染。
4. 升级天工配置台（WeaponEditor）与战斗引擎（CombatEngine、PlayerCharacter），提供图形化点位配置与实时连击战斗表现。
5. 剔除冗余配置项（攻击方式与行属灵威），动作与五行完全由形态与特性推导。
6. 解耦挥击刀芒机制：初始木刀保持紧凑近战（68px）且无刀芒，仅在装配【剑气】(`swordBeam`) 特性时触发外溢水墨弧光与增距。

- [x] `WeaponEditor.ts` 具备图片文件上传、在画板上交互点选“握持点”与“刃尖点”、旋转角微调与实时预览功能。
- [x] 移除配置台中的攻击方式与五行选单，改由兵刃形态与五行特性自动决断与展示。
- [x] 木刀范围调整为 68px 无剑气，挥斩不带弧光；【青钢剑】、【赤炎刀】装配【剑气】特性并成功触发延伸与弧光特效。

- [x] 全套单元测试（10个测试套件、41个测试）与端到端构建顺利通过。
