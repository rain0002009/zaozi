# 造字台与铸武台交互重构

## 目标
根据玩家反馈与截图审查，优化基地中「毛笔宣纸造字台」与「铸武台」的交互体验与界面美感：
1. 造字台文案去技术化，移除游戏无关的手写识别字数说明，增强沉浸感。
2. 汉字详情卡片换行修复，移除剧透式推荐与武器锻造提示，保留探索趣味。
3. 出征关口“关”字顶部留白与居中排版优化。
4. 快捷造字栏初始为空，移除配方查看，点击若笔画足够直接扣除并生成字。
5. 铸武台展示已生成字库存（有数量计数），支持无字数限制的多字槽位与拖拽放入/移出合成武器，锻造消耗字。
6. 默认武器重置为「木刀」（伤害 8，攻速 1.0），清除原「基础刀」等默认数据，初始字库与快捷栏均为空。

## 验收标准
- [x] 造字台副标题文案不再提及离线识别与 9,507 字库等元游戏内容。
- [x] 字详情卡片文案在卡片边框内正确换行，不超出右边界；不提示推荐字和武器锻造限定。
- [x] 出征关口顶部“关”字垂直居中于头部区域，不贴顶边。
- [x] 造字台下方快捷栏初始为空，成功手写造字后收录；点击快捷字在笔画足够时直接生成字并扣除笔画。
- [x] 铸武台展示玩家拥有的已造字库存（含计数），支持多字槽位拖拽放入，合成匹配成功后消耗字道具产出武器。
- [x] 初始默认武器仅有「木刀」（伤害 8，攻速 1.0），仓中无默认字。
