# 001-米字格拼字造字与多字组词铸武系统

## 目标
实现核心汉字构筑闭环：
1. **米字格造字台**：玩家在基地使用米字格交互画板拼装笔画，成功拼出汉字后解锁该字入库；
2. **铸武台**：玩家将字放入铸武槽，组词锻造武器（如「木」+「刀」=「木刀」，「火」+「刀」=「炎刀」等）；
3. **出征战斗实装**：角色装备不同词组武器出征，武器改变角色的攻击模组、攻击侧判定与弹道效果；
4. **角色表现极简化**：角色保持几何墨色圆圈，彻底剥离位图与复杂动画。

## 验收标准
- [ ] 基地界面增加【米字格造字台】（网格画板、笔画拖拽/点击放置、凝字判定、配方解锁）；
- [ ] 基地界面增加【铸武台】（选字放入槽位、词组武器生成、武器属性与效果展示）；
- [ ] `GameState` 支持字库管理、配方簿记录、词组武器数据持久化；
- [ ] 战斗场景 `GameScene` 接入多种词组武器的实机攻击效果（木刀的高速挥斩、炎刀的火焰刀光与灼烧、木弓的远程射箭等）；
- [ ] 全量 TypeScript 编译与 Vite 构建通过。
