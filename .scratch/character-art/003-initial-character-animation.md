# 初始角色形体与动作

## 目标
让初始角色“人”具备可读的身体、装备和动作，不再依靠半圆特效代替挥刀。

## 验收标准
- [x] 明确角色形体、三组朝向和模块化部件边界。
- [x] 明确透明 PNG、画布、锚点与文件命名规范。
- [x] 明确待机、移动、挥刀、翻滚、受击和死亡动作。
- [x] 明确攻击前摇、有效帧、收势与打断规则。
- [x] 提供可交给其他 AI 的角色与刀素材提示词。
- [x] 完成并验收正式图片素材。
- [x] 接入分层角色纹理与纸偶动作状态机。
- [x] 将挥刀伤害迁移到 112–155ms 有效帧并完成浏览器画面验证。
