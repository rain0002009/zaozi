# 06: 完整回归、联系表与旧路径退役

**What to build:** 将新角色动作的确定性测试和真实战斗回归接入可重复的项目流程，生成所有目标视口和动作联系表；确认视觉否决条件均未触发后，退役旧整腿素材、兼容路径和不可复现生成脚本。

**Blocked by:**

- 02: 距离驱动的自然步态
- 03: 三段攻击的全身下盘动作
- 04: 闪避、受击和死亡的全身姿势
- 05: 转身、连击换侧与状态过渡

**Status:** ready-for-agent

- [ ] 确定性动作测试覆盖步态相位、支撑脚漂移、关节连接、方向切换、动作中断和暂停恢复。
- [ ] 真实战斗浏览器回归覆盖左右攻击侧、单招锁定、连击换侧、闪避方向、受击打断、火球全方向瞄准和战斗判定。
- [ ] 回归覆盖逻辑画布、桌面视口和窄屏视口，并生成左右朝向、步态、攻击、闪避、受击、死亡和过渡联系表。
- [ ] 自动检查支撑脚漂移不超过 1.5 逻辑像素，关节和刀柄连接误差不超过 1 逻辑像素。
- [ ] 联系表未出现脚底滑动、双腿平行双轮廓、关节裂缝、脚部瞬移、攻击下盘待机、闪避方向错误或整体变形代替全身动作。
- [ ] 类型检查和生产构建通过。
- [ ] 新运行时 rig 和素材同步流程稳定后，删除旧整腿素材、兼容分支和过时生成脚本。
- [ ] 项目维护者查看联系表并确认最终动作观感。
