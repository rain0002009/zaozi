# 03: 三段攻击的全身下盘动作

**What to build:** 让短刀三段连击通过完整身体表达发力：第一刀下沉支撑，第二刀转移重心，第三刀蹬地前踏；攻击期间不再出现身体移动而下盘保持待机的滑行感。

**Blocked by:** 01: 新角色 rig 与分段下肢中立姿势

**Status:** ready-for-agent

- [ ] 第一刀在预备、命中和收势阶段表现前脚支撑、双膝下沉和后脚发力。
- [ ] 第二刀从第一刀收势连续进入，并表现重心向后脚转移和前脚卸力。
- [ ] 第三刀表现后脚蹬地、前脚踏出，并与现有前踏位移保持一致。
- [ ] 攻击期间停止普通步态循环，有限移动由招式专属下盘姿势吸收。
- [ ] 武器连击数据保留玩法数值、时序和动作名称，不直接依赖角色具体关节角度。
- [ ] 三段攻击的刀柄握点、身体关节连接和左右镜像保持正确。
- [ ] 既有攻击侧锁定、输入缓存、伤害时点、范围、击退和镜头反馈不变。
- [ ] 通过动作模块接口测试三段关键姿势的下盘重心、关节连接和姿势差异。
