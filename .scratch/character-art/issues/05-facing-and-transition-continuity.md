# 05: 转身、连击换侧与状态过渡

**What to build:** 让角色在普通转身、连击换侧、攻击受击打断、闪避结束和暂停恢复时保持支撑脚与动作相位连续，同时仍然即时响应鼠标攻击侧和真实移动方向。

**Blocked by:**

- 02: 距离驱动的自然步态
- 03: 三段攻击的全身下盘动作
- 04: 闪避、受击和死亡的全身姿势

**Status:** ready-for-agent

- [ ] 普通移动时攻击侧立即更新，视觉在约 80ms 内完成转身，支撑脚不瞬移。
- [ ] 转身过程中上半身与下盘分阶段交换近远腿职责，落脚连续可读。
- [ ] 连击进入下一招时可以改变攻击侧；上半身先转向，下盘在预备阶段完成重心和支撑脚转换。
- [ ] 单招中途仍锁定攻击侧，不因鼠标跨过中线而镜像。
- [ ] 攻击被受击打断时从当前姿势进入受击，不先跳回待机。
- [ ] 闪避和受击结束时从当前落脚状态进入待机或步态，不重置到任意相位。
- [ ] 暂停与恢复保留当前动作相位，不依赖绝对场景时间跳帧。
- [ ] 真实战斗场景验证左右转身、连击换侧、打断和暂停恢复均无脚部瞬移或姿势跳变。
