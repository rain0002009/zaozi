# 01: 新角色 rig 与分段下肢中立姿势

**What to build:** 将角色从两张整腿图片升级为统一的 14 层角色形体，让中立持刀姿势在真实游戏场景中保持清晰的前后层次、关节连接和刀柄握点连接。

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] 建立唯一的角色 rig 定义，集中描述部件、层序、锚点和默认姿势。
- [x] 接入远侧大腿、小腿、脚，近侧大腿、小腿、脚和独立衣摆，并保留现有上半身与短刀。
- [x] 编辑源素材使用统一高分辨率画布，运行时素材由确定性流程生成，透明边缘无白边或黑边。
- [x] 中立姿势中髋、膝、踝、脚底、肩、肘、腕和刀柄握点连接误差不超过 1 逻辑像素。
- [x] 远侧腿保持不透明、低对比并处于正确层级，不形成平行双轮廓。
- [x] 真实游戏场景可以显示新 rig，角色尺寸、碰撞半径、鼠标朝向和短刀握点行为保持现有规则。
- [x] 提供通过角色动作模块接口运行的中立姿势连接测试。
