# 02: 距离驱动的自然步态

**What to build:** 让角色在前进、后退、纵向侧移和斜向移动时按实际位移推进自然步态，脚掌在支撑期保持落点，起步、停步和方向切换不再产生滑步或双腿重影。

**Blocked by:** 01: 新角色 rig 与分段下肢中立姿势

**Status:** completed

- [x] 角色动作模块以实际位移推进步态相位，而不是使用绝对场景时间。
- [x] 前进、后退和纵向侧移使用可区分的步态；斜向输入在相邻步态间平滑混合。
- [x] 每约 110 逻辑像素完成一个左右脚周期，支撑期脚掌世界位置漂移不超过 1.5 逻辑像素。
- [x] 起步从稳定支撑姿势进入，停步在约 100–120ms 内收脚。
- [x] 方向切换保留当前支撑脚和相位，并在约 100ms 内混合到新方向。
- [x] 角色被边界阻挡或暂停时不继续推进步态相位。
- [x] 真实游戏场景中移动不会产生双腿平行双轮廓或脚底明显滑动。
- [x] 为步态相位、支撑脚、边界阻挡和方向混合增加确定性动作测试。
