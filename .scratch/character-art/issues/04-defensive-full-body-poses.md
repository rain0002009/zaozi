# 04: 闪避、受击和死亡的全身姿势

**What to build:** 让非攻击状态使用完整的支撑和失衡关系：闪避沿实际位移方向压低重心并跨步，受击屈膝失衡后由后脚支撑，死亡失去腿部支撑后按冲击方向倒下。

**Blocked by:** 01: 新角色 rig 与分段下肢中立姿势

**Status:** ready-for-agent

- [ ] 闪避沿实际闪避速度方向表现压低、收刀、跨步和收势；无移动输入时使用鼠标方向。
- [ ] 闪避撞到边界后根据实际剩余位移提前收势，不表现虚假的滑行。
- [ ] 闪避保持现有时长、速度、无敌窗口和冷却规则。
- [ ] 受击从当前姿势在约 30–40ms 内进入屈膝失衡姿势，并由后脚重新支撑。
- [ ] 受击时头部和持刀臂略晚于躯干回弹，且现有受击时长与连击重置保持不变。
- [ ] 死亡先失去腿部支撑并屈膝，再沿最后一次冲击反方向或当前面对方向的侧后方倒下。
- [ ] 短刀先脱手或落地，身体保持倒地轮廓，不依赖整体纵向压缩或淡出代替动作。
- [ ] 为闪避、受击、死亡及其打断恢复增加确定性姿势测试和真实场景验证。
