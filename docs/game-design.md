# 汉字世界 - 游戏设计文档

## 世界观

异世界入侵，老祖宗以大愿力把现在的世界变成了一个由汉字组成的世界，给了人们一线生机。

- 所有物质的本质是笔画，石头、树木、人都是笔画堆叠而成
- 玩家操控初始的"人"，通过消灭异世界怪物获得笔画
- 怪物也被汉字化，名字决定可掉落的笔画
- 最终消灭入侵者，还原原来的世界

## 核心循环（Roguelite）

```
基地（准备）→ 进入地图 → 探索区域 → 击败怪物（获得笔画）
→ 选择分支 → 继续深入（奖励加成）或返回基地
→ 基地合成字/升级角色 → 再次进入地图（更难的区域）
→ 击败最终Boss → 二周目
```

## 笔画系统

### 笔画类型
横(一)、竖(丨)、撇(丿)、捺(㇏)、点(丶)、折(㇇)、钩(亅)、提(㇀)等

### 品质等级

| 品质 | 颜色 | 品质系数 |
|------|------|----------|
| 普通 | 白 | 1.0 |
| 优秀 | 绿 | 1.2 |
| 精良 | 蓝 | 1.5 |
| 史诗 | 紫 | 2.0 |
| 传说 | 红 | 3.0 |

### 品质提升规则
- 10个同品质笔画 → 1个高一档品质笔画
- 例：10白 → 1绿，10绿 → 1蓝，10蓝 → 1紫，10紫 → 1红

### 掉落规则
- 怪物名字决定可掉落笔画（只掉名字中包含的笔画）
- 随机掉落，无保底机制
- 有稀有笔画追踪（缺的笔画掉率提高）
- 越厉害的怪物掉的笔画越稀有

## 合成系统

### 核心机制（类Minecraft工作台）
- 笔画自由拼装 → 部件（偏旁部首）→ 字
- 全靠玩家脑洞自由组合
- 拆解部件/字时，随机丢失部分笔画
- 组合失败不消耗材料

### 配方表（分类型维护）
- 武器表：刀、剑、枪、戟、弓...
- 防具表：盾、甲、盔...
- 技能表：光、火、雷、风...
- 饰品表：戒、环、珠...
- 身体表：手、足、头、目...

### 配方簿
- 合成成功 → 记录配方 → 下次一键合成
- 只显示字名，不显示所需材料
- 无推荐配方系统

## 装备系统

### 字属性计算
```
字属性 = 基础差异 × 品质系数 + 特殊效果
- 基础差异：刀 vs 剑 vs 枪，各有基础值
- 品质系数：白1.0 / 绿1.2 / 蓝1.5 / 紫2.0 / 红3.0
- 特殊效果：红字可能附带吸血、暴击等
```

### 自然类型
- 具体字直接装备：刀=武器，盾=防具
- 抽象字作为技能：光=技能（附魔效果）
- 组合字有独立类型：光剑=武器（匹配表决定）
- 匹配失败 = 合成失败

### 容量系统
- 容量消耗 = 字数（非笔画数）
- "刀" = 1字 = 1容量
- "光剑" = 2字 = 2容量
- 初始角色：50字容量
- 升级/更换角色：容量变化

### 装备槽位（人体结构）

| 槽位 | 数量 | 说明 |
|------|------|------|
| 双手 | 2 | 武器 |
| 手指 | 10 | 戒指 |
| 手腕 | 2 | 护腕 |
| 头部 | 1 | 头盔 |
| 颈部 | 1 | 项链 |
| 身体 | 1 | 盔甲 |
| 脚部 | 1 | 鞋 |

- 特殊角色（如哪吒3头6臂）有额外槽位
- 装备字只能按槽位功能使用（刀只能挥砍，要刀气需装备"剑气"技能）

## 技能系统

| 类型 | 机制 | 示例 |
|------|------|------|
| 被动型 | 装备即生效，修改基础属性 | 力大如牛(+力量)、身轻如燕(+敏捷) |
| 触发型 | 随普攻释放，有冷却时间 | 剑气(每次攻击附带) |
| 计数型 | N次普攻后触发 | 待补充 |
| 主动型 | 按技能键释放 | 火球(发射火球) |

## 战斗系统

### 操作方式
- 键盘WASD移动 + 鼠标攻击（PC端）
- 闪避操作

### 近战朝向与连击
- 近战只有左、右两个攻击侧；鼠标相对角色的水平位置决定角色侧身朝向，移动方向不改变朝向。
- 鼠标位于角色中线附近时保持当前朝向；单招期间锁定攻击侧，连击的下一招可以重新读取鼠标位置并转身。
- 近战不能向正上或正下追踪目标，玩家需要通过走位把目标放入武器的侧向攻击范围。
- 玩家逐次点击并在输入窗口内续接武器连击；每种近战武器拥有自己的招式数量、节奏、轨迹、范围与效果。
- 远程武器、投射物和法术仍可使用独立的全方向瞄准规则。

### 防御机制
- 防御 = 装备/技能/基础属性提供比例抵挡
- 受伤扣生命值，归零则死亡

### 怪物攻击模式
- 不同怪物有不同攻击模式
- 攻击方式与名字相关
- 示例：[火]狼 = 扑咬 + 喷火球

## 地图系统（Roguelike）

### 区域结构
- 每局5-8个区域
- 分支选择（玩家选择路径）
- 区域大小类似元气骑士

### 区域Boss
- 每个区域都有Boss
- 更多血量和攻击手段
- 掉落更稀有笔画和更多低级笔画

### 连胜奖励
- 连续进入下一局 → 稀有笔画掉落率提升
- 最高+30%
- 中途死亡 → 全部清零

## 角色系统

### 角色解锁
- 条件：收集特定字 + 该角色对应装备
- 示例：解锁"二郎神"需要"二""郎""神"三字 + 三尖两刃刀

### 角色升级
- 消耗：笔画
- 提升：字数容量 + 基础属性
- 无洗点机制

### 角色列表

| 角色 | 字数容量 | 特殊能力 | 解锁条件 |
|------|----------|----------|----------|
| 人 | 50 | 无 | 初始 |
| 二郎神 | 80 | 三眼（额外槽位） | "二""郎"+"三尖两刃刀" |
| 哪吒 | 100 | 3头6臂（额外槽位） | 待定 |
| 孙悟空 | 90 | 72变（特殊技能） | 待定 |

## 二周目系统

- 敌人更强
- 稀有笔画掉落概率更大
- 部分角色仅二周目可解锁
- 无新区域
- 最终Boss偷袭机制：
  - 击败区域Boss后有概率偷袭
  - 击败偷袭不会杀死Boss
  - 但最终关卡时Boss会变弱

## 存档系统

| 时机 | 说明 |
|------|------|
| 手动存档 | 仅在基地可操作 |
| 自动存档 | 死亡或获胜回归后系统自动保存 |
| 保存内容 | 角色等级、已合成的字、已解锁的配方、已解锁的角色 |

## 视觉风格

- 国风水墨画风
- 角色、装备与特效可以表达汉字的含义，但不要求轮廓包含对应汉字的字形
- 初始“人”采用轻度俯视的三分之二侧身人形，按鼠标左右位置镜像，不再使用“人”字躯干
- 装备具体显示（刀=刀的图形，火=火焰附魔效果）
- 技能效果：火球=发射火球，剑气=附带剑气
- 初始角色“人”的分层素材与动作规格见 `docs/art/initial-character-art-requirements.md`
