# ADR-0005: 分段角色 Rig 与确定性素材发布

## 状态
已接受

## 背景
角色原先使用两张整腿图片。腿部只能作为刚性整体摆动，无法在走路、攻击和闪避中分别控制髋、膝和踝；衣摆也与躯干合并，难以维持自然的遮挡关系。运行时如果分别手写部件锚点和层序，素材与动作代码容易逐渐失配。

## 决策
角色采用 14 部件的分段 rig：远侧和近侧腿各拆为大腿、小腿、脚，并将衣摆独立，上半身和短刀继续使用既有的分段结构。

`src/entities/CharacterRig.ts` 是运行时部件名称、纹理键、层序、关节锚点和中立姿势的唯一定义。编辑源素材统一保存在 `art/characters/ren/source/` 的 1024×1024 透明画布中；`scripts/build_character_rig_assets.cjs` 以确定性流程生成 `public/assets/characters/ren/source/` 下的 256×256 运行时素材，并对透明像素执行颜色扩边，避免缩放采样产生白边或黑边。

迁移阶段保留原角色的逻辑尺寸、碰撞规则、左右镜像方式和短刀握点。后续动作通过同一 rig 接口驱动各关节，不再增加整腿版本的平行实现。

## 后果
- 步态、攻击和闪避可以独立控制髋、膝、踝及衣摆，但动作实现需要持续保证相邻关节连接。
- 素材修改需要先编辑高分辨率源文件，再运行确定性发布脚本；不直接手改运行时图片。
- 新增或重命名部件时，需要同步更新素材构建清单；该脚本只允许从编辑源发布运行时图片，并保持 CommonJS，以免仅为读取 TypeScript 定义而引入额外构建工具。
- 中立姿势与真实战斗场景测试负责验证部件数量、层序、关节误差、镜像和短刀握点兼容性。
