# ADR-0002: Combat Readability And Run Flow

## 状态
已接受；其中“普攻使用鼠标指针方向扇形”的近战瞄准规则已被 ADR-0004 取代

## 背景
最小 demo 中，攻击没有方向判定，怪物一击即死，闪避按住会重复触发，死亡会直接重启。玩家很难判断攻击是否生效，也无法在区域之间形成可读的节奏。

## 决策
- 普攻使用鼠标指针方向的 116° 扇形，并以怪物距离作为同扇形内的优先级。
- 怪物拥有随区域成长的生命值，受击会闪烁并击退，击杀后掉落可拾取笔画。
- 闪避使用 `JustDown` 触发，提供短暂无敌和冷却提示。
- 清空区域后保留短暂收集窗口；死亡进入明确的结果界面，`P` 可暂停/继续。

## 后果
- 战斗信息密度更高，玩家可以通过攻击扇形、生命条、掉落物和 HUD 反馈理解状态。
- `GameScene` 仍是原型阶段的单场景实现，后续若加入 Boss、技能和存档，应将掉落、玩家状态和波次抽到独立系统。
