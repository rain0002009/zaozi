# ADR-0014: 字谜秘境高奖励区域与局内解谜古碑造字

## 状态
已接受 (Accepted)

## 背景
在先前的版本与 ADR-0012 中，造字与锻造仅限定在基地的毛笔宣纸造字台和铸武台进行（纯局外基地养成），出征过程中仅搜刮怪物掉落的携带笔画。

为了丰富出征途中的策略抉择、引入汉字文化谜题互动，并提供高风险高回报的博弈机会，提出在出征路线中引入高奖励区域：**【字谜秘境】**。玩家需要在门前通过破解汉字谜语并当场消耗字作为钥匙开启秘境，进入后可在安全免战与死斗翻倍之间进行两阶段博弈。

## 决策

### 1. 路线节点与概率出现 (Route Node & Encounter)
- **节点类型**：在出征的路线节点选择阶段，有概率（推荐 15%~25%）刷出特殊的金色秘境图标节点【字谜秘境】。
- **自主抉择与放弃**：玩家可自主选择是否前往。到达秘境前，若玩家发现自身【携带笔画】不足以造出谜底字，或解不出字谜，可随时点击【转身离去】，安全返回路线选择并前往其他常规路线节点，不产生任何惩罚。

### 2. 解谜古碑与局内造字 (Riddle Stele & In-Run Crafting)
- **局内专属交互**：秘境门前树立【解谜古碑】，古碑镌刻字谜谜面（如“一口吃掉牛尾巴”）。
- **呼出宣纸画板**：交互古碑时呼出米字格宣纸画板（复用 HandwritingService 手写识别与拓扑匹配），读取当前出征的【携带笔画】。
- **谜底即钥匙与字生命周期**：
  - 玩家根据谜面现场手写书写汉字（如「告」）。
  - 点击【提交验证】：
    - **匹配正确**：若玩家携带笔画充足且识别出的字即为谜底字，立即扣除对应携带笔画，凝出汉字并瞬间作为钥匙消耗开门，不留多余闲置字实体；
    - **匹配错误**：碑文泛起微光提示“此字非此谜之钥”，不扣除任何笔画与字实体，画板保留或一键重置，玩家可继续尝试。
- **求助提示机制**：
  - 玩家若卡壳，可主动消耗 1~2 根携带笔画激活古碑印记获取提示：
    - **第一重线索（字形/结构）**：提示部首与结构（例如：“口字旁 / 上下结构”）；
    - **第二重线索（字意/组词）**：提示关联词汇（例如：“宣告、告别”）。

### 3. 秘境殿堂与两阶段博弈抉择 (Two-Stage Gamble)
开启石门进入秘境殿堂后，设立两座神龛供玩家抉择：
1. **【静谧宝阁】（Safe Altar / 中等奖励）**：
   - 免战直接领取供奉：包含稀有高阶笔画（战后带回基地）+ 1 件高阶词组武器或局内强力符印。
   - 领取后安全完成该区域，前往下一路线节点。
2. **【死斗试炼】（Trial Altar / 翻倍顶级大奖）**：
   - 激活后传送到试炼斗兽场，遭遇秘境专属字阵守护兽，具有独特的汉字机制词条。
   - **胜利**：获得翻倍顶级奖励（包括绝品金色笔画、限定传说级词组武器、全属性强化符）。
   - **失败保命机制**：试炼中若角色生命值归零，触发古碑护体禁制，角色保留 1 点生命值被强制传送出秘境，无法获取试炼奖励，但出征不中断（残血继续下一节点）。

## 后果
- 首次打破了出征阶段“纯搜刮无造字”的单一循环，将手写造字玩法自然融入局内探险与解谜，极大增强了汉字主题的探索感与文化沉浸感。
- 引入了两阶段风险收益博弈（免战稳健 vs 死斗搏命），兼顾了不同水平玩家的心态，并且死斗失败保命设计避免了过度挫败感。
- 局内造字严格限制在“古碑验证开门”的闭环内（谜底验证成功才扣笔画销字，不残留闲置临时字），保证了出征背包系统的简洁性，未破坏基地字库与词组武器的核心经济体系。
