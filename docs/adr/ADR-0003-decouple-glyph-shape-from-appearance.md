# ADR-0003: 汉字语义与视觉字形解耦

## 状态
已接受

## 背景
要求角色、装备和特效的外形复现对应汉字，会显著增加造型、拆件和动作制作难度，并容易让字形辨识与自然人体动作互相妨碍。

## 决策
汉字继续决定角色身份、装备类别、能力和视觉主题，但角色、装备与特效不必在轮廓中复现对应字形。美术可以通过服装、器物、颜色和效果表达字义；缺少字形元素不构成验收失败。初始“人”保留规则身份，但采用正常人形。

## 后果
- 角色和武器可以优先保证轮廓、动作与装备连接的可读性。
- 同一个字可以拥有多种视觉诠释，不需要维护强制的字形骨架。
- 汉字主题主要由造字、装备规则、命名和语义效果承载，美术仍需避免变成与汉字世界无关的通用奇幻风格。
