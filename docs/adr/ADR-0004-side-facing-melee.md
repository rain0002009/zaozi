# ADR-0004: 侧身角色与左右近战攻击侧

## 状态
已接受

## 背景
正面角色配合鼠标 360° 瞄准时，斜上、斜下和跨身挥刀会造成肩、手臂、刀与身体透视不协调。继续为任意角度修补纸偶关节会提高素材与动作复杂度，仍难获得稳定的动作观感。

## 决策
近战角色采用轻度俯视的三分之二侧身轮廓，只按鼠标的水平位置在左右之间镜像。近战武器攻击固定的左侧或右侧区域，不追踪正上与正下目标；每种武器使用独立连击。远程能力保留全方向瞄准。

本决策取代 ADR-0002 中“普攻使用鼠标指针方向扇形”的近战瞄准规则；ADR-0002 的生命值、受击、翻滚、掉落和区域节奏决策继续有效。

## 后果
- 近战动作可以围绕少量稳定姿势制作，刀与手臂不再随鼠标任意旋转。
- 玩家必须通过走位处理角色正上与正下的敌人，站位成为近战武器的明确成本。
- 新近战武器需要各自定义连击、范围和效果，不能直接复用短刀动画。
