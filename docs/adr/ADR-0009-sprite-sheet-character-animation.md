# ADR-0009: 放弃分段纸偶 Rig，改用逐帧序列帧（Sprite Sheet）驱动角色动作

## 状态
已接受（取代 ADR-0005 与 ADR-0008，部分修改 ADR-0006 与 ADR-0007 中关于 Rig 关节装配与 IK/FK 求解的部分）

## 背景
分段纸偶 Rig（无论 14 部件还是 10 部件）在 2D 细节上存在固有的画风与运动缺陷：
1. 肢体为刚性 2D 平面切件，旋转时缺乏透视体积变化与肌肉/布料动态褶皱；
2. 关节交界处存在不可避免的重叠缝隙、裁切毛边与穿模硬块；
3. 拼装出的动作带有明显的“剪纸提线木偶”僵硬感，难以呈现水墨武侠行云流水的动作张力。

## 决策
1. **全面转向逐帧序列帧（Sprite Sheet）**：放弃部件拼装，采用经典 2D 逐帧手绘序列帧驱动角色动作。当前阶段聚焦基础动作：
   - `idle`（中立待机）：4 帧循环（呼吸起伏、发带与衣摆微动）；
   - `walk`（移动步态）：8 帧循环（完整的迈步、接触、蹬地、摆腿周期）。
2. **手部挂点（Socket 模式）承载装备**：角色序列帧保持空手自然状态，通过数据配置记录每帧手部坐标与角度 `(handX, handY, rotation)`。装备武器或字时，独立武器 Sprite 绑定到手部挂点实时跟随，无需为不同武器重绘人物帧。
3. **保留距离驱动步态相位**：移动步态仍由实际位移推进动画帧索引，防止被障碍阻挡时产生滑步。

## 后果
- 彻底消除了关节切口、重叠白边、肢体脱节与纸偶僵硬感，每一帧都是完整自然的水墨画。
- 极大简化了角色渲染管线（从复杂的 10~14 个 Sprite 矩阵变换收敛为单张 Sprite 序列帧播放）。
- 换装与不同体态的边际成本高于骨骼复用，但通过手部挂点解耦了武器系统，满足当前 Roguelite 核心玩法需求。
