# ADR-0010: 采用「土豆兄弟 (Brotato)」风格程序化弹性角色动作架构

## 状态
已接受（取代 ADR-0008 与 ADR-0009）

## 背景
在经历 10 部件纸偶 Rig（ADR-0008）与 12 帧序列帧（ADR-0009）的迭代验证后，发现人形写实比例在 2D 动作肉鸽游戏中面临巨大瓶颈：
1. **写实解剖结构的固有复杂性**：正常人体比例的关节铰接、衣褶透视与步态相位极难在 2D 平面或拼装中保持协调，容易产生关节穿模、断层与剪纸僵硬感；
2. **制作与扩展成本高昂**：每次微调动作、换装或新增武器都需要重新调整十几组切件或手绘大量帧序列；
3. **动作打击感与流畅度受限**：低帧率序列帧缺乏现代动作肉鸽必备的 60fps 弹性挤压与打击形变。

用户提议全面改用「土豆兄弟 (Brotato)」风格。

## 决策
1. **水墨圆豆游侠形象**：
   - 角色形象改为 Q 版圆润豆状体型（水墨墨韵、红色侠客发带、坚毅大眼、黑白短打）；
   - 彻底废弃人形关节拆分，采用单一完整高精度角色主体 Sprite，底部锚点对齐双足。
2. **纯代码程序化弹性动画引擎（Juicy Procedural Animation）**：
   - **待机 (Idle)**：体积守恒的呼吸挤压拉伸（Squash & Stretch: Y 轴拉伸时 X 轴收缩，60fps 正弦波自然微动）；
   - **移动步态 (Waddle Bounce)**：标志性左右倾斜摇摆（±8°~10°）+ 腾空弹跳（Bounce），地面阴影动态跟随；
   - **攻击突进 (Attack Lunge)**：基于连招阶段的程序化形变与位移冲刺（突刺压缩、横斩蓄力、挑击纵向伸展）；
   - **闪避与受击 (Dodge & Hurt)**：极致压扁滑行与受挫震颤。
3. **极简高效的渲染与扩展架构**：
   - 角色渲染节点收敛为单精灵 + 动态阴影，支持无缝朝向镜像翻转；
   - 所有动画参数（呼吸频率、摇摆角度、弹跳幅度、攻击冲刺强度）均暴露为可调配置，支持检视器实时微调。

## 后果
- 彻底消除了关节白边、拼装缝隙、解剖失真与骨骼穿模问题；
- 动画表现实现 60fps 原生丝滑插值，兼具极强的 Q 弹表现力与幽默感；
- 极大简化了角色代码复杂度与维护成本，为主线肉鸽玩法的迭代扫清了美术与动画障碍。
