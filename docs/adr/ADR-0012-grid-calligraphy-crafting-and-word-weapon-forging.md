# ADR-0012: 米字格拼字造字与多字组词铸武系统设计

## 状态
已接受

## 背景
在 `/grill-with-docs` 需求对齐中，针对「笔画合成字」与「字合成武器」的核心玩法规则与时机，明确了以下三项关键设计方向：
1. **笔画合成字**：采用**米字格/九宫格拼字模式**，玩家在网格画板上手动摆放/拼接笔画，拼出合法汉字后完成造字，最大化汉字拆解与书写的特色体验；
2. **字合成武器**：采用**多字组词构筑（两字/多字成武）**，将不同的字合成为复合词组武器（例如：木 + 刀 = 木刀，金 + 刀 = 铁刃，火 + 刀 = 炎刀）；
3. **合成时机**：采用**纯局外基地养成**，出征负责搜刮笔画带回基地，所有造字与武器锻造均在基地完成，配齐装备后出征。

## 决策

### 1. 纯局外基地养成循环 (Base-Centric Crafting)
- **战斗阶段**：击败不同怪物掉落特定笔画（如狼怪掉「丿」「㇏」，残碑掉「一」「丨」，火妖掉「丶」等）；出征结算（通关或主动撤退）将笔画存入基地【仓中笔画】。
- **基地阶段**：
  1. 在【米字格造字台】消耗笔画拼出汉字；
  2. 在【铸武台】选择已拥有的字锻造【词组武器】；
  3. 装备武器与属性字后，开启下一轮出征。

### 2. 米字格造字台 (Mi-Grid Calligraphy Board)
- **画板机制**：
  - 提供标准的传统书法米字格（米字虚线、8 个方位笔划槽位或网格落笔区）；
  - 玩家点击/拖拽库存中的笔画放置到画板中；
  - 提供【清空】、【撤销】与【凝字】按钮；
- **汉字拓扑识别库（第一批支持字）**：
  - **兵刃字**：「刀」（丿 + ㇇）、「弓」（㇇ + 一 + ㇇）、「盾」（一 + 丨 + 丿 + ㇇ 等）；
  - **属性字**：「木」（一 + 丨 + 丿 + ㇏）、「火」（丶 + 丿 + 丿 + ㇏）、「金」（人 + 王 + 丶 + 丶）、「石」（一 + 丿 + 口）；
  - **数理/基础字**：「一」、「十」（一 + 丨）、「人」（丿 + ㇏）、「大」（一 + 人）。
- **配方簿记录**：首次成功在米字格中拼出的字自动收录至配方簿，后续可在配方簿中查看解法。

### 3. 铸武台与词组武器系统 (Weapon Forge & Compound Weapons)
- **锻造机制**：
  - 铸武台包含两个或三个字槽（如【属性/材质字】+【兵刃/核心字】）；
  - 将不同的字放入槽位，锻造为对应的【词组武器】：
    - 「木」+「刀」=「木刀」：轻灵迅捷，攻速提高 35%，连斩节奏极快；
    - 「火」+「刀」=「炎刀」：每次斩击划出赤色烈焰刀光，命中附带点燃与范围灼烧；
    - 「金」+「刀」=「金刀」：厚重锋利，攻击范围扩大，破甲并附带强力击退；
    - 「石」+「刀」=「石刃」：势大力沉，挥斩附带地裂震波与眩晕效果；
    - 「木」+「弓」=「木弓」：远程直线射出木箭；
    - 「火」+「弓」=「烈火弓」：发射爆裂火箭，命中爆炸产生火海；
- **战斗即时生效**：角色装备词组武器出征，武器直接驱动战斗中的普攻模组、弹道生成与判定逻辑。

## 后果
- 确立了游戏独一无二的“书写拼字 + 组词铸武”核心差异化玩法；
- 摆脱了传统肉鸽枯燥的纯数值升级，赋予汉字文化深度与操作乐趣；
- 研发重心明确，下一步将在 `BaseScene` 中构建【米字格造字台】与【铸武台】的交互界面与合成逻辑。
