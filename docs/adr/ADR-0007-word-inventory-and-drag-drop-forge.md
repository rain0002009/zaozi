# ADR-0007: 汉字实体库存化与铸武台多字拖拽合成

## 状态
已接受

## 上下文
在先前的版本中：
1. 造字台下方的已解锁汉字仅为展示列表，且初始默认填充了「刀」「木」「十」。
2. 铸武台固定为双槽位（前缀字 + 核心字），且字被视作永久解锁的无限复用标志，而非消耗性实体。
3. 造字台界面展示了“支持 9,507 汉字离线识别”等元技术文本，打破了游戏沉浸感；且字详情卡片剧透了推荐合成字及武器锻造关系。
4. 初始默认武器为「基础刀」（伤害 18），并解锁「木刀」（伤害 16，攻速 1.4）。

玩家要求：
1. 去除元技术文案与剧透，强化汉字世界探索感。
2. 将字转化为具备数量的实体（消耗品）：造字消耗笔画产出字，铸武消耗字产出武器。
3. 铸武台突破两字限制，支持动态放入 1 至任意多字，并支持拖拽交互。
4. 默认初始武器变更为「木刀」（伤害 8，攻速 1.0），清除其余默认武器，初始字库为空。

## 决策
1. **字实体库存化 (`wordInventory: Record<WordId, number>`)**：
   - 玩家通过造字台（手写或快捷点击）凝字成符，消耗笔画，获得对应字的实体存量（`wordInventory[wordId] += 1`）。
   - 快捷造字栏初始为空，成功制造过的字自动进入快捷栏；点击快捷字即可直接消耗笔画凝字。
2. **铸武台支持动态多字与拖拽 (`Word-Drag-and-Drop Forge`)**：
   - 铸武台展示玩家当前持有的字实体列表及存量。
   - 铸武槽位支持 1 至多个字动态排布，玩家可拖拽字放入槽位，或点击槽位移出。
   - 铸武台根据槽中放入的字序列匹配词组武器，并在锻造时扣减相应字实体存量。
3. **初始数据与数值重置**：
   - 初始武器仅保留「木刀」，属性调整为：伤害 8，攻速 1.0。
   - 初始默认字库与快捷字栏均为空。

## 后果
- 玩家对“笔画 $\to$ 字 $\to$ 武器”的循环感知更加具象且具有资源管理感。
- 铸武台不仅限于双字，后续可无缝支持三字、四字成语及词组武器的扩展。
- 界面移除了暴露技术的元描述与剧透，增强了沉浸感与探索未知组合的乐趣。
