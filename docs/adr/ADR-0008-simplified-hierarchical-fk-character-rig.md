# ADR-0008: 精简分段层级 FK 角色 Rig 与分阶段基础动作构建

## 状态
已接受（部分取代 ADR-0005 与 ADR-0006 中关于 14 部件拆分及 Phaser 逆运动学 IK 求解的部分）

## 背景
原先 14 部件分段 Rig（大腿/小腿/脚掌三段分离）在 AI 散件生成与两段式腿部 IK 反解中，因坐标变换冲突与解算奇异点导致关节断裂、翻折与动作崩坏。同时，攻击连击与复杂状态过早耦合，阻碍了基础形体与步态的稳定性调优。

## 决策
1. **部件精简为 10 部件**：下肢精简为大腿与小腿（含脚），双臂精简为大臂与小臂（含手），保留头部与躯干。各散件独立生成并统一水墨游侠风格；基础动作保持空手自然状态，武器解耦为独立挂载槽位。
2. **驱动改为层级正向运动学（FK）**：放弃腿部 IK 反解，采用父子层级变换（髋->膝->踝，肩->肘->腕）与平滑角度周期函数，彻底消除关节撕裂与脱节风险；继续保持由实际位移推进步态相位以防止撞墙滑步。
3. **分阶段交付与验收**：第一阶段仅实现并锁定「中立姿势静态拼装与关节锚点对齐」；确认无误后再推进第二阶段「距离驱动 FK 步态动效」。

## 后果
- 关节具有天然闭合性，物理上杜绝拆解断裂与膝盖反折。
- 散件生成难度与贴图错位风险大幅降低。
- 牺牲了脚掌与复杂地形的微观贴合（微观踝关节反解），但在 2D 俯视视角下大幅提升了动作流畅度与稳定性。
