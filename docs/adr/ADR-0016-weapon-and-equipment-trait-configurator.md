# ADR-0016: 铸武台武器与装备特性配置台设计

## 状态
已接受

## 背景
在之前的实现中，铸武台锻造的词组武器（`COMPOUND_WEAPONS`）采用硬编码的数据字典，武器效果以固定描述和固定 stats 为主。随着构筑深度加深，策划与开发者需要能够灵活地：
1. 配置铸武台可以生成的武器与防具；
2. 新增武器、删除武器并调整基础属性（攻击力、攻速、射程等）；
3. 装配不同的战斗特性（如击退、火焰、一击必杀、吸血等）并调节特性的强度参数；
4. 自由输入汉字组合作为锻造配方，而不局限于固定分类；
5. 提供可视化管理页面，并能导出规范的 JSON 数据以供项目维护。

## 决策

### 1. 独立路由调试管理页 (Dedicated Web Editor Route)
- 在主入口中检测 URL 参数 `?view=weapon-editor`；
- 独立于 Phaser Canvas，采用基于 DOM 的现代响应式暗黑水墨风界面，极大提升文字输入、表单选择、特性拖拽和 JSON 预览的交互体验与效率；
- 游戏内铸武台提供一键跳转链接（同时支持随时从控制台或地址栏直达）。

### 2. 装备类型解构与基础属性
将装备拆分为基础大类（`category`）：
- **武器 (weapon)**：支持近战（melee）与远程（ranged），基础属性涵盖基础伤害（damage）、攻速倍率（attackSpeed）、攻击距离（range）、基础击退（knockback）、弹道速度（projectileSpeed）；
- **防具 (armor)**：基础属性涵盖减伤百分比（damageReduction）、额外生命值（bonusHp）、反弹冲击（blockReflect）等；
- **宝具 (talisman)**：可承载全局被动增益或特殊字法法则。

### 3. 特性系统 (Traits System)
每件装备支持装配 0 至多个特性（Traits）。首批提供 10 种核心特性：
1. **击退 (knockback)**：击退力度、硬直时长；
2. **烈焰灼烧 (burn)**：秒伤、燃烧时长、点燃概率；
3. **一击必杀 (instantKill)**：斩杀触发概率、残血处决阈值；
4. **奔雷连环 (chainLightning)**：跳跃目标数、传导伤害衰减率；
5. **极寒迟滞 (chill)**：减速幅度、持续时间、冰冻时长；
6. **墨血汲取 (lifeSteal)**：吸血转化率；
7. **狂风穿透 (pierce)**：穿透目标数、风刃范围；
8. **荆棘反噬 (thorns)**：防具近战伤害反弹比例；
9. **震地眩晕 (stun)**：眩晕概率、眩晕时长、震波半径；
10. **墨影余波 (echo)**：墨影触发概率、余波伤害系数。

### 4. 纯 JSON 代码生成与导入导出
- 装备配置器支持可视化操作；
- 右侧实时生成符合 TypeScript 类型定义的 JSON 数据；
- 提供一键复制 JSON、导出 `weapons-config.json` 文件以及导入现有 JSON 文件的能力，方便快速同步至代码库。

## 后果
- 实现了装备数值与特性的数据驱动，大幅提升游戏构筑设计与调优效率；
- 为后续战斗引擎（Combat System）引入更丰富多元的状态效果和连击特效奠定了清晰的数据架构；
- 保留向后兼容性，现有 14 款经典词组武器均完整作为默认配置纳入。
