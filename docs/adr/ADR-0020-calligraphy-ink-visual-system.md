# ADR-0020: 古风书法水墨与金箔沉浸视觉体系架构

## 状态
已接受

## 背景
游戏以古代书法、仓颉造字及熔字为武为核心文化题材。先前的界面采用了通用的扁平纯色矩形、基础无衬线/默认衬线字体以及简易按钮，缺乏浓郁的书法意蕴、水墨纸境与空间层次，无法满足古风书法主题游戏的沉浸感要求。
为实现高水准的艺术呈现，用户制定了 9 项严苛的视觉要求：
1. 全局深墨绿 × 暗金 × 宣纸白配色，禁止纯色，所有背景必须具备渐变+纹理；
2. 标题使用「霞鹜文楷」，正文使用「Noto Serif SC」，笔画按钮采用书法字体；
3. 毛笔笔触造型按钮、墨迹边缘、选中态泛金光、点击触发墨滴溅射微动效；
4. 真实宣纸画板（纤维纹理 + 朱砂红米字格 + 做旧泛黄暗角）；
5. 笔画按钮呈现竹简令牌造型、纵向木纹、选中描金边；
6. 金色双重浮雕出征关卡面板，大字“关”采用鎏金书法体与外发光；
7. 全屏慢速飘落的墨点与金箔碎屑粒子；
8. 悬浮于宣纸之上的内外立体阴影空间层次；
9. 0.3s 入场过冲回弹缓动（`Back.easeOut`）。

## 决策

### 1. 程序化 Canvas 动态材质生成器 (`InkTextureGenerator`)
为避免静态巨幅位图素材带来下载延迟与高分屏模糊失真，在 `src/visuals/InkTextures.ts` 中实现高精度程序化 Canvas 材质生成：
- **`tx_ink_bg` (1024×768)**：双重墨绿径向与线性渐变底色 + 远山水墨剪影 + 宣纸纤维杂质噪点 + 沉浸暗角；
- **`tx_paper_board` (288×288)**：泛黄做旧宣纸基底 + 随机茶渍纤维 + 四周茶褐色暗角 + 朱砂红虚线米字格（含对角线、九宫格）；
- **`tx_bamboo_token` / `tx_bamboo_token_active` (84×50)**：竹简令牌圆角造型 + 纵向木质纤维线条 + 倒角高光与投影 + 选中态浮雕鎏金边与外发光光晕；
- **`tx_gold_relief_gate` (158×480)**：双重浮雕暗金外框 + 倒角明暗线 + 四角如意云纹浮雕花；
- **`tx_brush_btn_*`**：毛笔枯笔笔触轮廓、飞白微纹、暗金与朱砂色渐变；
- **`tx_ink_particle` / `tx_gold_particle`**：晕染水墨滴与菱形金箔碎屑。

### 2. 墨韵环境与微动效引擎 (`InkAtmosphereManager` & `InkVFX`)
在 `src/visuals/InkAtmosphere.ts` 中构建专属氛围与视觉动效引擎：
- **全屏漂浮粒子群**：38~45 颗墨点与闪烁金箔以正弦波水平摆动及匀速垂直下沉，金箔粒子具备旋转与透明度微闪；
- **点击墨滴溅射 (`spawnInkSpatter`)**：交互按钮与槽位点击时，向外以极坐标径向射出 6~14 颗墨滴与金砂，结合减速曲线并在 320ms 内渐隐消失；
- **立体层次投影 (`createDropShadow`)**：所有悬浮面板（画板、关卡、槽位、卡片）附带半透明深色偏移投影，营造浮在桌案宣纸之上的空间透视；
- **0.3s 过冲回弹入场 (`applyOvershootEntrance`)**：面板展示与 Tab 切换应用 `Back.easeOut` 弹性缩放渐显。

### 3. 工坊与主场景深度落地
在 `BaseScene`、`CalligraphyWorkshop` 与 `ForgeWorkshop` 中彻底替换原有矩形绘制，应用新的材质、字体链、阴影与笔触按钮。

## 后果
- 彻底告别扁平单调色块，形成高度统一直觉的古风书法美学世界；
- 运行时零外部大图资产加载等待，Canvas 动态生成在高 DPI 屏幕下极其锐利细腻；
- 所有测试通过，构建打包无损。
