# ADR-0024 统一特性模型、六大兵刃连击序列与兵刃拓片锚点系统

## 决策背景与核心决定

此前武器装备体系分为基础属性（`baseStats`）、五行（`element`）与法则特性（`traits`）三套数据通道，且连击系统仅有单一短刀。我们决定：
1. 确立「一切皆特性」：彻底废除独立的 `baseStats` 与 `element` 字段，数值（伤害、攻速、范围等）、元素（火、冰、雷等）与机制（吸血、灼烧、反伤等）全部统一为 `TraitInstance` 结构，并重命名为通俗简练的规范词。
2. 规范六大兵刃形态（刀、枪、剑、戟、斧、弓）差异化连击模组，连击数覆盖 2~5 段（斧 2、刀 3、戟 3、弓 3、枪 4、剑 5）。
3. 引入「兵刃拓片与双锚点系统」：支持上传自定义图片作为兵刃外形，采用归一化双点坐标（握持锚点 + 刃尖/发射点）配合朝向校准角，实现外形贴图与程序化水墨双模平滑回退。

## 方案考量与权衡

- **纯平铺 vs 统一特性元数据分类**：
  放弃了维护三套独立属性面板的做法，统一通过特性管线解析；通过元数据打标分类，既确保游戏核心“汉字赋予特性”的高度统一，又保持计算性能与配置可读性。
- **多点骨骼 vs 极简双点锚点**：
  曾考虑手柄前后多点与发光点绑定，但对图片素材要求苛刻且配置繁琐。改用「握持点（旋转中心） + 刃尖点（弧光/发射点） + 角度校准」的极简方案，兼具极低上手门槛与高精度表现力。
- **配置表单精简与五行/动作自明性**：
  剔除配置台中冗余的“攻击方式”与“行属灵威”下拉框。攻击模式由兵刃形态（弓为远程、盾为防御、其余近战）天然决定，行属直接由装配的五行特性推导，杜绝配置冲突。
- **刀气/剑气机制按特性按需触发**：
  打破此前所有近战挥刀必带大范围半月刀气的做法。初始木刀仅有 68px 紧凑身前物理判定，不外溢光效；只有装配了【剑气】(`swordBeam`) 特性的神兵利刃才激发水墨弧光与增距，层次鲜明。
