# ADR-0021: 归字营文房古案实物场景化与阴影伪影根除

## 状态
已接受

## 背景
在 ADR-0020 引入书法水墨材质与动效体系后，试玩与视觉评估中暴露出两大破坏游戏沉浸感的关键问题：
1. **生硬黑框瑕疵（Black Frame Artifacts）**：原 `InkVFX.createDropShadow` 采用 Phaser 基础几何图形 `scene.add.rectangle(...)` 制作投影。由于缺乏高斯模糊滤镜，半透明硬边黑色矩形在深色木质与墨绿背景上显得尤为生硬突兀，如同错位杂乱的黑色外边框；
2. **现代后台表单感重，缺乏游戏画面感**：
   - 顶部导航栏如同网页选项卡，平铺的笔画计数条缺乏材质感；
   - 工坊内部充斥大段教程说明长句（如“在宣纸画板上运笔书写以墨化符，书毕自动推演可辨之字...”），界面形似后台管理系统而非神机莫测的古代文房与神兵铸炼地；
   - 画板、候选字区与锻造台呈现孤立色块拼接，缺乏置身古代书案桌面的整体实物空间感。

## 决策

### 1. 文房古案与工坊实物场景化（Physical Scholar Desk Metaphor）
彻底废弃网页式卡片与管理表单布局，重塑为一张沉浸式古风文房木案营房：
- **`tx_scene_desk_bg` (1024×768)**：深沉紫檀/红木文案材质，带有清晰细腻的木质年轮肌理、中央温润烛光晕染（Warm Vignette）与远山水墨淡影；
- **`tx_inventory_scroll` (928×64)**：顶部由扁平统计条改为展开的仿古绢帛横幅长卷，配有红木轴头，自然收纳八种库存笔画；
- **`tx_token_sign_craft` / `tx_token_sign_forge` (156×42)**：功能导航由网页 Tab 变为悬挂在营房上方的紫檀金边令签牌匾，切换带墨滴溅射与金色浮雕光晕；
- **`tx_scroll_desk` (296×296)**：书写画板从平铺卡片进化为桌面摊开的丝绢装裱立轴画卷，具备红木滚轴轴头、陈年泛黄宣纸基底与朱砂红虚线米字格；
- **`tx_furnace_panel` (470×140)**：铸武台打造为重型玄铁熔炼古鼎，内嵌内凹双熔炼槽位与火光微芒；
- **`tx_preview_altar` (240×140)**：神兵展示位设计为髹漆兵刃玄案，配有太极祥云八卦浮雕；
- **`tx_seal_slot` / `tx_word_token` / `tx_weapon_card`**：候选字与字库卡片均具象化为青玉印章、镶金木符与黑漆铭牌。

### 2. 彻底根除硬边黑色矩形投影
- 移除 `InkVFX.createDropShadow` 及其所有调用，严禁在无模糊滤镜的 Canvas/WebGL 环境下使用硬边半透明黑矩形伪装阴影；
- 将深度立体感转移至 Canvas 烘焙材质层：通过多层径向暗角、内凹槽位阴影（Recessed Inner Shadow）与双层暗金浮雕描边（`0xc49f49` / `0x485a4a`），在保证 0 像素杂边的同时呈现自然光影层次。

### 3. 极简游戏化文案与微交互
- 剔除所有冗长说教文案，提炼为四字古韵游戏术语：
  - 造字案：由“识别候选与部件列表”精简为「推演灵字」与「熟识古字」；
  - 铸武台：由“选择两个字进行组合”提炼为「熔炉槽位」、「仓中字阵」与「待纳二字，合铸神兵」；
  - 结算：采用「凯旋归营」与「收 入 仓 中」。

## 后果
- 彻底根除了画面中突兀的黑框伪影，所有面板边沿整洁严丝合缝；
- 归字营全面升华为置身文房木案的古代奇幻世界，大幅提升视觉品质与游戏代入感；
- 保持全部 21 项单元测试与 TypeScript 严苛编译通过。
