# ADR-0022: 印令按键规范重塑、仓中笔画被动化与行路图排版重构

## 状态
已接受

## 背景
在完成归字营场景化重构与黑框根除（ADR-0021）后，玩家试玩体验反馈了三项突出的交互与排版痛点：
1. **仓中笔画残留无意义点击**：过去网格造字时代残留了“点击笔画选中并高亮”的逻辑，而在手写宣纸画卷普及后，该交互已没有任何游戏逻辑消费，导致操作迷惑；
2. **按键样式怪异割裂**：
   - 归字营与造字台使用了贝塞尔曲线绘制的“毛笔笔触按钮”（`tx_brush_btn_*`），两端严重内凹、中间鼓胀，形态如失真纺锤或叶片，随机生成的飞白细丝显得粗糙琐碎，且文字对比度不足；
   - 行路图（`RouteScene`）与开始菜单（`MenuScene`）则直接使用了原生 HTML 风格的实心直角纯色矩形（`backgroundColor: '#d7c796'`），风格完全割裂；
3. **行路图文字溢出与垂直重叠**：
   - Phaser 3 默认的 `wordWrap` 机制严格依赖英文空格分词（`line.split(' ')`）。无空格的连续中文句子被当成单个单词，无法被引擎断行，导致单行文字直接刺出路线卡片（卡片宽 230px，文本长达 380px）；
   - 卡片高度仅 300px，居中原点排布使得折行后的多行描述与底部位于 `y + 112` 的“踏入”纯色按钮产生直接垂直碰撞与重叠。

## 决策

### 1. 仓中笔画彻底转为纯被动资源看板
- 移除 `BaseScene` 中 `selectedStrokeForPlacement`、`strokeButtons` 与 `strokeImages` 等状态缓存；
- 移除令牌点击事件、手型光标与高亮贴图切换，将顶部展开画卷中的八种笔画定位为静态、宁静的存量展示板；
- 保持文字动态刷新（`refreshInventoryUI`），玩家注意力完全下沉至挥毫书画与熔字铸武。

### 2. 统一全游「印令按键」视觉规范体系
- 废弃扭曲的贝塞尔纺锤毛笔曲线，重构 `InkTextures.generateBrushButton`：
  - 采用规范平整的微圆角长矩形（$r = 5\text{px}$）；
  - 烘焙内凹质感渐变（鎏金、朱砂、乌木墨玉三种色调）；
  - 搭配细腻的双层金属包边与微光高光线；
  - 四角点缀古铜暗金微铆钉饰扣，塑造庄重尊贵的古代令签/木匾质感；
- 拔除所有原生的 `backgroundColor` 纯色直角块，全游按钮（出征、清空、撤销、凝字、踏入、迎战、开始、结算）统一接入印令按键贴图体系；
- 规范文本配色与对比度：金色按键统一使用 `#1a241b` 深墨铜色粗体字，深色按键使用 `#dbe6d8` 玉白色，禁用态使用 `#687c6b` 柔灰绿色。

### 3. 引擎级中文避头尾断行算法与行路图流式排版
- 创建 `src/visuals/textWrap.ts`，实现遵循中文排版规范（避头尾法则 Kinsoku Shori）的断行算法：
  - 严格避免行首出现结束标点（`，。、；：！？）』」》”’`）；
  - 严格避免行尾出现起始标点（`（『「《“‘`）；
  - 优先在逗号等自然意群停顿处断句；
- 重塑 `RouteScene` 卡片空间与纵向节奏：
  - 卡片高度由 300px 适度扩展至 344px，宽度由 230px 增至 244px（首领卡 340px）；
  - 卡片中心下移至 `y = 375`，自上而下严格流式排布：
    - 印章徽记与篆字：`y - 106`（半径 32px）
    - 区域主标题：`y - 50`（24px 文楷粗体）
    - 危险度批注：`y - 20`（13px 思源宋体）
    - 多行描述：`y + 30`（13px，行距 6px，经算法规范折为 2~3 行）
    - 踏入印令按钮：`y + 124`（高度 36px/44px）
  - 描述下沿与按钮上沿保持超过 45px 的安全呼吸间距，杜绝文字溢出与重叠。

## 后果
- 仓中笔画交互更加纯粹，去除了冗余伪交互；
- 全局按键美术风格实现了高度统一，消除了扭曲怪异和生硬色块两种极端瑕疵；
- 行路图中文断句自然整齐，卡片排版疏密得当，大幅提升出征决策阶段的游戏质感；
- 单元测试覆盖率提升（新增 `textWrap.test.ts`），23 项测试全部通过，打包构建零阻塞。
