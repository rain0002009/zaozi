# ADR-0011: 采用极简几何圆圈占位角色，全面聚焦笔画与字合成玩法

## 状态
已接受（取代 ADR-0008, ADR-0009, ADR-0010 中关于角色美术与动画表现的部分）

## 背景
此前在角色视觉表现上先后尝试了 10 部件纸偶 Rig、12 帧逐帧序列帧以及土豆兄弟式单图弹性动画。但连续的视觉迭代消耗了大量精力，且美术资产与动画尚未达到满意效果，严重拖慢了核心玩法的验证进度。

用户明确要求：
1. 暂时放弃角色动画；
2. 清理所有临时生成的角色位图素材；
3. 角色采用极简几何圆圈代替；
4. 优先集中力量完成**「笔画合成字」**与**「字合成武器」**的核心玩法与构筑系统。

## 决策
1. **角色形体极简几何化**：
   - 角色表现为一个极简墨色圆环（半透明绿色底 + 浅米色描边 + 红色朝向指示点 + 核心 '人' 字标识）；
   - 保留完整的战斗与移动接口（朝向、位移、攻击突进、闪避、受击判定）；
   - 彻底剔除所有外部位图切片与序列帧依赖，零资源加载负担。
2. **重心转移至汉字核心玩法构筑**：
   - 核心任务推进收敛至：
     - **笔画收集与合成字（Strokes -> Characters）**；
     - **字合成/赋能武器（Characters -> Weapons / Affixes）**；
     - **局内与局外造字循环验证**。

## 后果
- 彻底摆脱了美术资产生成与动画穿模/比例失调的泥潭；
- 研发重心完全回归核心玩法——汉字构筑 Roguelite 的特色机制；
- 后续待合成玩法闭环、手感调优完成后，再行决定角色视觉资产的最终落地方式。
