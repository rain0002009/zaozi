# 术语表 (Glossary)

> 规范术语及边界以根目录 `CONTEXT.md` 为准。本文件保留品质、槽位、技能分类等详细设计表。

## 核心概念

| 术语 | 英文 | 定义 |
|------|------|------|
| 笔画 | Stroke | 世界基本构成单元，有类型（横竖撇捺点折钩提等）和品质（白绿蓝紫红） |
| 部件 | Component | 笔画拼装的中间产物（偏旁部首），拆解会随机丢失笔画 |
| 字 | Character | 部件/笔画拼装的最终产物，作为装备/技能/道具载体 |
| 怪物 | Monster | 异世界入侵者，被汉字化，名字决定可掉落笔画 |
| 角色 | Role | 玩家可操控的形态，初始为"人"，后期可解锁神话角色 |

## 品质系统

| 品质 | 颜色 | 品质系数 |
|------|------|----------|
| 普通 | 白 | 1.0 |
| 优秀 | 绿 | 1.2 |
| 精良 | 蓝 | 1.5 |
| 史诗 | 紫 | 2.0 |
| 传说 | 红 | 3.0 |

品质提升规则：10个同品质 → 1个高一档品质

## 装备系统

| 术语 | 定义 |
|------|------|
| 字数容量 | 角色可装备字的总上限，按字数计算（"刀"=1，"光剑"=2） |
| 装备槽位 | 由人体结构决定：双手2武器、手指10戒指、手腕2护腕、头部1头盔、颈部1项链、身体1盔甲、脚部1鞋 |
| 配方表 | 合成字的匹配规则，类Minecraft工作台，分类型维护 |
| 配方簿 | 已成功合成的字的记录，可一键再次合成 |

## 技能类型

| 类型 | 机制 | 示例 |
|------|------|------|
| 被动型 | 装备即生效，修改基础属性 | 力大如牛(+力量)、身轻如燕(+敏捷) |
| 触发型 | 随普攻释放，有冷却时间 | 剑气(每次攻击附带) |
| 计数型 | N次普攻后触发 | 待补充 |
| 主动型 | 按技能键释放 | 火球(发射火球) |

## 战斗系统

| 术语 | 定义 |
|------|------|
| 翻滚 | 玩家闪避操作 |
| 防御 | 装备/技能/基础属性提供比例抵挡 |
| 生命值 | 受伤时扣除，归零则死亡 |

## 地图系统

| 术语 | 定义 |
|------|------|
| 区域 | 每局包含5-8个区域，玩家选择分支路径 |
| 区域Boss | 每个区域都有，更多血量和攻击手段，掉落更稀有笔画 |
| 连胜奖励 | 连续进入下一局，稀有笔画掉落率+30%上限，死亡清零 |

## 角色系统

| 术语 | 定义 |
|------|------|
| 角色解锁 | 收集特定字 + 该角色对应装备 |
| 角色升级 | 消耗笔画，提升字数容量和基础属性，无洗点 |
| 二周目 | 敌人更强，稀有笔画掉落率更大，部分角色仅二周目可解锁 |

## 基地功能

| 功能 | 说明 |
|------|------|
| 合成字 | 笔画 → 部件 → 字 |
| 升级角色 | 消耗笔画提升属性 |
| 存储系统 | 存储多余的笔画和字 |
| 图鉴系统 | 查看已发现的字和怪物 |
| 配方簿 | 查看已解锁的合成配方 |
| 商店 | 低阶笔画兑换高阶笔画 |
| NPC对话 | 获取线索和任务 |

## 存档系统

| 时机 | 说明 |
|------|------|
| 手动存档 | 仅在基地可操作 |
| 自动存档 | 死亡或获胜回归后系统自动保存 |
| 保存内容 | 角色等级、已合成的字、已解锁的配方、已解锁的角色 |
